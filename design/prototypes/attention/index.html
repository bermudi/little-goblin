Reading this mockup

  • All names, titles and facts here are made up. "During the outage" shows what a memory failure should look like. The error wording there is written by hand.
  • Two details are placeholders: the notifications line is made up, and the last recall time is a sample.
  • Buttons only change this page. Nothing reaches Goblin.

What this needs that Goblin does not have yet

  • The real error from Hindsight. The outbox only stores "remote operation failed".
  • Failures grouped by cause, with a true count. Today's list stops at 10.
  • Conversation names on memory rows. Today they show IDs.
  • A way to bring dropped exchanges back ("Save them now"). Dismiss can't be undone today, and this waits for memory tuning.
  • For skill updates: the installed files next to the proposed files, so the card can show a per-file diff.
  • Approve, reject, install and discard working from the card, using the same owners as today.
